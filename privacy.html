Privacy policy · last updated October 5, 2026

Who uses Deck

Deck is a personal dashboard used only by the household that runs it. It has no other users.

What Google data Deck accesses

With the owner's permission, Deck uses the YouTube Data API with the read-only scope (youtube.readonly) to read:

  • the list of channels the owner is subscribed to, and
  • public information about recent videos from those channels (title, channel, thumbnail, length, publish time).

Deck does not read email, contacts, watch history, comments, playlists you made, or any other Google data.

How the data is used and stored

The data is used only to show a list of new videos on the owner's own screen. It is stored on the owner's home computer (the sign-in token in a file readable only by the owner, and up to 14 days of video listings) and is deleted after that. It is never sold, shared, transferred to anyone else, used for advertising, or used to train AI models.

Google API Services User Data Policy

Deck's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Deck also follows the YouTube Terms of Service, and its use of YouTube data is subject to the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deck then stops reading YouTube data, and the stored listings expire within 14 days.

Contact

Questions about this policy can be raised as an issue on this project's GitHub repository.
